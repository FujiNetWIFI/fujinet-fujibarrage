# far.txt -- the NES game's overlay functions called from outside their
# overlay (tools/nes/mkfar.py; the 5200's tools/atari5200/far.txt): each
# gets a wrapper in the fixed banks that puts the overlay's bank in R6
# ($8000), calls it, and puts the caller's back. The overlay's own is
# renamed ovl_<name> when it is compiled. tools/nes/farcheck.py fails a
# build that calls across without one. A far function must not be given a
# pointer into its caller's bank (it reads with its own bank in); a pointer
# into its own (cat_item's, to cat_name) is fine.
#
