# far.txt -- the 7800 game's overlay functions called from outside their
# overlay (tools/nes/mkfar.py; the NES's tools/nes/far.txt): each gets a
# wrapper in the core that puts the overlay's bank in the window ($A000-
# $BFFF is a bank's own), calls it, and puts the caller's back. The
# overlay's own is renamed ovl_<name> when it is compiled.
# tools/nes/farcheck.py fails a build that calls across without one. A far
# function must not be given a pointer into its caller's bank (it reads
# with its own bank in); a pointer into its own is fine.
#
